# Windows 用户数据与卸载测试用例

## 基本信息

- **用例编号**：`WIN-DATA-UNINSTALL-001`
- **测试目标**：验证 Windows 安装版的用户数据目录展示、目录打开、卸载时保留数据和删除数据功能。行为事实见 `docs/architecture-overview.md`「存储」。
- **测试平台**：Windows 10 或 Windows 11
- **测试对象**：正式生成的 YINLI `.exe` 安装包
- **测试方式**：完整执行两遍，分别验证“保留用户数据”和“删除用户数据”。

## 测试前提

1. 使用正式 Windows 安装包，不要使用开发模式。
2. 测试前确认没有其他 YINLI 或 `backend-server.exe` 进程运行。
3. 测试账号具有当前用户目录的读写权限。
4. 准备一个可以重新安装的同版本安装包。

## 一、首次安装

1. 双击 YINLI Windows 安装包。
2. 使用默认选项完成安装。
3. 启动“引力 YINLI”。
4. 等待首页和后端状态显示正常。
5. 进入“系统设置”。

### 预期结果

- 应用正常启动。
- Chat 页面正常加载。
- “系统设置”中出现“用户数据”区域。
- 显示一个绝对路径，通常类似：

```text
C:\Users\<当前用户名>\.agent-workstation
```

- 页面不显示 API Key 内容。
- 用户数据路径不是应用安装目录，例如不能是：

```text
C:\Program Files\...
```

## 二、打开用户数据目录

1. 在“系统设置 → 用户数据”区域点击“打开目录”。
2. 观察 Windows 文件资源管理器。

### 预期结果

- Windows 文件资源管理器被打开。
- 资源管理器直接进入页面显示的用户数据目录。
- 目录中可以看到或逐步生成类似内容：

```text
data
logs
secrets
backend-process.json
```

3. 返回 YINLI，创建测试对话：

```text
这是卸载保留数据测试，请记住编号 TEST-001。
```

4. 等待对话完成。
5. 返回系统设置，确认用户数据路径没有变化。

## 三、验证“保留用户数据”卸载

1. 关闭 YINLI 窗口。
2. 等待几秒，打开任务管理器，确认没有正在运行的 `backend-server.exe`。
3. 打开 Windows“设置 → 应用 → 已安装的应用”。
4. 找到“引力 YINLI”，点击“卸载”。
5. 卸载程序出现询问时选择：

```text
否 / 保留用户数据
```

### 预期结果

- 卸载程序显示用户数据处理提示。
- 默认选项为“保留用户数据”。
- 应用安装目录被移除。
- 以下目录仍然存在：

```text
C:\Users\<当前用户名>\.agent-workstation
```

- 目录中的数据没有被删除。

## 四、重新安装并验证数据恢复

1. 再次运行 YINLI Windows 安装包。
2. 启动应用。
3. 进入 Chat 历史记录。
4. 查找之前创建的测试对话：

```text
这是卸载保留数据测试，请记住编号 TEST-001。
```

5. 进入“系统设置 → 用户数据”。

### 预期结果

- 应用正常启动。
- 历史测试对话仍然存在。
- 用户数据路径仍指向原来的目录。
- 点击“打开目录”仍然可以进入该目录。
- 不需要重新创建默认配置。

## 五、验证“删除用户数据”卸载

再次执行卸载：

1. 关闭 YINLI。
2. 从 Windows“已安装的应用”中卸载 YINLI。
3. 卸载询问时选择：

```text
是 / 删除用户数据
```

### 预期结果

- 卸载程序明确说明会删除：
  - 对话
  - Agent
  - Skill
  - MCP
  - Memory
  - 日志
  - 本地配置
  - API Key
- 应用安装目录被删除。
- 当前用户数据目录被删除：

```text
C:\Users\<当前用户名>\.agent-workstation
```

- 如果存在历史目录，也应被删除：

```text
C:\Users\<当前用户名>\AppData\Roaming\agent-workstation-desktop
```

- 卸载完成后不存在 `backend-server.exe` 进程。
- 如果删除失败，提示应为：

```text
应用已卸载，但部分用户数据未能删除，请手动检查用户数据目录。
```

- 删除失败时不能提示“用户数据已删除”。

## 六、最终判定

### 通过条件

- [ ] 安装、启动、Chat 和系统设置正常。
- [ ] 系统设置显示真实用户数据目录。
- [ ] “打开目录”进入正确目录。
- [ ] 选择保留数据后，重新安装可以恢复测试对话。
- [ ] 选择删除数据后，固定用户数据目录被删除。
- [ ] 卸载不会删除用户主目录中的其他文件。
- [ ] 卸载完成后没有残留 `backend-server.exe`。

### 失败条件

- [ ] 设置页显示安装目录或错误目录。
- [ ] “打开目录”无反应或打开错误位置。
- [ ] 选择保留数据后数据丢失。
- [ ] 选择删除数据后用户数据仍然存在且没有提示。
- [ ] 卸载删除了 `.agent-workstation` 以外的用户文件。
- [ ] 卸载完成后仍有 `backend-server.exe` 残留。
