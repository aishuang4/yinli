# Web 托管剩余事项

> 状态：2026-10-09。邮箱注册、按账号隔离、管理员停用 / 删除和 key2api 模型已经在 `master`。在线事实见 `docs/architecture-overview.md`「托管账号与桌面登录」。本文不再保留已经落地的阶段计划。

仍未接到工作台的只有桌面端登录：

- 桌面端填写托管服务地址，用邮箱登录。令牌只写入本机 `hosted-account.json`，不写入聊天记录，也不改本机 `models.json`。
- 登录后选择器增加 `platform:` 模型。退出、过期或停用后该分组消失。本机历史和本机自配模型仍在。
- 未配置服务地址时，不显示平台模型。

这些约束继续有效：Web 与桌面不同步会话和文件；平台 Key 不下发到桌面；同一邮箱可以同时在两端登录，数据仍然各管各的。桌面安装包的签名和公证见 `docs/electron-packaging-plan.md`。
