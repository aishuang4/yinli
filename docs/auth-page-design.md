# 账号页视觉设计

## 设计依据

2026-10-14 查看以下产品的实际登录页。登录页会随产品更新，下表记录本次可见布局，不视为长期产品合同。

| 参考页面 | 本次观察 | 引力采用的方向 |
| --- | --- | --- |
| [Linear](https://linear.app/login) | 居中登录标题，登录方式纵向排列，主任务集中。 | 保持认证区集中、辅助入口克制。 |
| [Notion](https://www.notion.so/login) | 大面积白底留白，产品定位与登录标题上下排列，邮箱作为首要操作。 | 用一句话解释产品用途，邮箱登录作为核心流程。 |
| [Figma](https://www.figma.com/login) | 品牌标识独立，宽表单字段，主要按钮与重置、注册链接层级明确。 | 增强品牌识别，拉开主要操作与辅助入口层级。 |
| [Vercel](https://vercel.com/login) | 独立顶栏品牌与注册入口，邮箱操作优先，其余登录方式分组。 | 账号操作独立顶栏，表单区保持清晰。 |

Claude 页面遇到安全验证，本次没有把它的登录布局纳入结论。

## 当前视觉方案

账号页采用深绿品牌区与独立表单双栏。使用现有 `favicon.svg` 中的引力绿，品牌文案为「让想法，成为作品」。轨道图形呼应产品名称；文件卡片表现资料整理、文档和表格生成场景，并明确标注「工作场景示意」。展示内容是装饰性插画，不展示用户任务或实时状态。

表单沿用设计系统的 `TextField` / `PasswordField` / `FormError` / `Button`。登录、注册、验证邮箱与重置密码共用同一外壳；忘记密码紧邻密码字段，注册入口只保留登录表单下方的「创建账号」。验证码为空时重置按钮显示「发送验证码」，输入后显示「重置密码」，与现有处理逻辑一致。

表单区支持暗色主题。右上角只显示太阳／月亮图标，默认无边框、无底色，悬停时浮现圆形底色；点击后图标旋转、缩放并淡入淡出，表单配色同步柔和过渡。保留可访问名称和悬停提示，系统开启「减少动态效果」时关闭过渡。所有账号流程共用切换入口，复用 `settingsStore` 的主题与持久化，刷新及登录后保留选择。窄于 760px 时只保留紧凑品牌栏与表单，短窗口允许整体滚动。没有新增依赖、外部字体或远程图片。

账号页直接以 `100dvh`（回退 `100vh`）铺满视口，不依赖上层 `AntdApp` 的百分比高度。去掉固定最小高度，随可用高度收紧标题、插画、字段间距与留白，常见桌面窗口一屏显示；较矮窗口隐藏装饰插画和辅助文案，优先保留完整表单。极小窗口或超长错误内容超出时，仅表单区提供可达性滚动兜底，不裁掉操作按钮。

## 实现边界

- `AuthScreen.tsx` 负责账号表单与模式展示。
- `AuthBrandPanel.tsx` 负责静态品牌场景。
- `auth.css` 负责账号页专属布局，原全局认证样式已移出。
- 服务模式判断、认证请求、Cookie 与桌面会话行为仍由 `HostedSessionGate` 和认证服务负责。

视觉验收使用包含实际 `AntdApp` 容器的独立预览入口，不连接真实认证服务，不发送验证码或创建账号。实际登录由现有托管模式入口展示。
